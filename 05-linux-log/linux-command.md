# Linux测试常用命令
## 文件目录
ls、ls -l、cd、pwd、mkdir、rm、cp、mv、chmod、chown

## 日志查看
cat、more、less、tail -f

## 进程端口
ps aux、ss -tulnp

## 服务管理
systemctl status xxx
systemctl restart xxx
systemctl start xxx
systemctl stop xxx

## 网络测试
ping ip地址
curl 网页地址

## MySQL操作
mysql -u root -p
show databases;
use 库名;
show tables;
select * from 表名;
