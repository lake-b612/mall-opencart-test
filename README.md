# OpenCart电商商城测试项目
## 项目简介
被测系统：OpenCart开源B2C电商商城，部署在Ubuntu22.04虚拟机，LAMP环境。
模拟电商完整业务：用户注册登录、商品浏览、购物车、下单支付、订单管理、后台商品管理。

## 使用技术
- 功能测试：等价类、边界值、场景法
- Linux：查看Nginx/Apache日志、进程、端口、文件权限
- MySQL：校验注册、订单业务数据库数据，编写业务校验SQL
- 缺陷管理：整理bug清单，包含复现步骤、优先级、预期实际结果

## 仓库目录说明
- 01‑requirement：业务需求梳理
- 02‑testcase：功能测试用例
- 03‑bug：发现的缺陷清单
- 04‑mysql‑check：数据库校验SQL与记录
- 05‑linux‑log：服务器日志排查、Linux操作记录
- 07‑test‑report：整体测试报告

## 项目收获
完整完成web项目从需求梳理→编写测试用例→执行测试→提交bug→数据库校验→服务器日志排查→输出测试报告完整流程。
