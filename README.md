# OpenCart 电商商城测试项目

## 项目简介
被测系统：OpenCart 开源 B2C 电商商城 **3.0.3.9**，部署在 **Ubuntu 22.04** 虚拟机（Apache2 + MySQL 8.0 + PHP）的 LAMP 环境，通过 VMware 运行。

- 前台地址：`http://192.168.119.128/`
- 后台地址：`http://192.168.119.128/admin`
- 数据库：`opencart_db`（136 张表，前缀 `oc_`）

覆盖电商完整业务：用户注册登录、商品浏览、购物车、下单支付、订单管理、后台商品与销售管理，共 19 个业务模块。

## 使用技术
- **功能测试**：等价类划分、边界值分析、场景法、错误推测
- **测试设计**：Xmind 绘制测试点脑图
- **Linux**：查看 Apache 日志、进程端口、文件权限，定位 500 / 403 问题
- **MySQL**：编写业务校验 SQL，核对注册、下单等落库数据一致性
- **缺陷管理**：缺陷清单（复现步骤、严重级别、优先级、根因分析）+ 用例误报审核

## 仓库目录说明
- `01-requirement`：业务需求梳理（19 模块 / 77 测试关注点）
- `02-testcase`：功能测试用例（556 条）+ Xmind 测试点脑图
- `03-bug`：缺陷清单 + 用例误报审核记录
- `04-mysql-check`：数据库校验 SQL 与记录（含脏数据验证）
- `05-linux-log`：服务器日志排查与 Linux 操作记录
- `06-test-report.md`：整体测试报告（V2.0）
- `env-deployment.md`：环境搭建与安全收尾（删除 install 目录、配置文件权限收口）
- `img`：操作与结果截图（共 71 张）
