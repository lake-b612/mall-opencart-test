# OpenCart功能测试用例
|用例ID|模块|用例标题|前置条件|操作步骤|预期结果|
| ---- | ---- | ---- | ---- | ---- | ---- |
|F‑001|用户注册|正常注册新用户|访问商城注册页面|1.输入合法用户名<br>2.输入符合规则密码<br>3.填写邮箱<br>4.勾选协议，提交注册|注册成功，跳转登录，数据库新增用户记录|
|F‑002|用户注册|密码长度不足注册|进入注册页|1.用户名合法<br>2.输入短密码(3位)<br>提交|页面提示密码长度不满足，注册失败，数据库无新增|
|F‑003|登录|账号密码正确登录|已注册账号|1.输入账号密码，点击登录|登录成功，跳转商城首页，显示当前用户名|
|F‑004|登录|密码错误登录|存在注册账号|1.账号正确，密码错误，提交|提示账号密码错误，无法登录系统|
|F‑005|购物车|正常添加商品到购物车|已登录，商品存在库存|1.进入商品详情页<br>2.输入购买数量1，加入购物车|购物车数量+1，购物车内展示该商品|
|F‑006|购物车|添加超过库存数量商品|商品库存为5|1.商品详情填写数量10，加入购物车|系统拦截，提示超出库存，无法加入购物车|
|F‑007|订单下单|正常提交订单|登录，购物车有商品，填写收货地址|1.进入结算页面<br>2.选择地址，确认下单|订单创建成功，生成订单号，库存扣减，数据库订单表新增记录|
|F‑008|后台商品|后台下架商品|管理员账号登录后台|1.商品列表找到目标商品，操作下架|前端商城该商品不可购买，后台状态显示已下架|
