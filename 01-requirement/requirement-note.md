## 1. 商城首页模块

### 业务描述

商城前台默认首页，是用户访问平台的核心入口，集中展示平台广告、推荐商品、合作品牌等核心内容，为未登录游客提供全站基础浏览服务。

### 核心功能

1. 首页轮播广告展示，支持手动切换浏览

2. 推荐商品展示，包含商品图片、名称、售价、简介信息

3. 商品快捷操作功能，支持加入购物车、加入收藏、商品对比

4. 合作品牌轮播展示，展示平台入驻品牌

5. 全站底部导航、资讯、客服、账号快捷入口展示与跳转

### 测试关注点

- 未登录游客无权限限制，可正常浏览首页全部内容

- 后台新增、修改、停用轮播广告，前台实时同步生效

- 首页推荐商品信息与后台商品配置参数完全一致

- 商品各类快捷操作按钮交互正常，无点击失效、报错问题

- 页面底部所有链接可正常跳转至对应页面

### 关联数据库表

`oc_banner`、`oc_banner_image`、`oc_product`、`oc_product_description`、`oc_module`（推荐位 Featured 模块配置）、`oc_manufacturer`、`oc_manufacturer_to_store`（品牌轮播）、`oc_information`、`oc_information_description`（底部资讯入口）

## 2. 商品分类与列表模块

### 业务描述

为用户提供商品分类导航与列表展示服务，支持分类跳转、商品筛选、排序、分页，是用户批量浏览、筛选商品的核心模块。

### 核心功能

1. 顶部一级、二级商品分类导航展示与跳转

2. 分类对应商品列表展示，图文信息完整渲染

4. 商品排序功能，支持价格、人气等维度排序

5. 列表分页功能，支持多页商品切换浏览

6. 页面面包屑导航，记录浏览路径，支持返回上级页面

7. 商品对比功能，支持多选商品进行参数对比

- 分类跳转精准匹配对应商品列表，无跳转错误、空白页面

- 价格、品牌、规格筛选条件生效，精准过滤对应商品

- 排序、分页功能正常生效，商品展示顺序、数量符合规则

- 面包屑导航路径准确，可正常回退至上一级页面

- 商品对比功能正常加载参数，对比数据准确无误

`oc_category`、`oc_category_description`、`oc_category_path`（多级层级）、`oc_category_to_store`、`oc_product`、`oc_product_to_category`、`oc_manufacturer`、`oc_filter`、`oc_filter_description`、`oc_filter_group`、`oc_filter_group_description`、`oc_product_filter`、`oc_category_filter`（筛选条件）

## 7. 购物车模块

### 业务描述

支持未登录游客与已登录用户将商品加入购物车，实现商品暂存、待下单功能。未登录游客购物车数据依靠会话 ID 标识存入数据库；用户完成登录后，将会话 ID 对应的购物车记录归属到当前登录用户名下，完成购物车数据合并。

### 核心功能

1. 商品列表、商品详情页可将商品加入购物车
2. 页面顶部购物车图标实时展示购物车内商品数量、合计总价
3. 进入购物车页面，无商品时展示空购物车友好提示
4. 未登录用户点击结算，自动跳转登录 / 注册页面
5. 用户登录后，将会话对应的游客购物车数据迁移合并为该用户的购物车数据

### 测试关注点

- 未登录状态下，可以正常添加商品，购物车数量、价格实时更新；数据库`oc_cart`表生成记录，`customer_id=0`，依靠`session_id`区分不同游客
- 浏览器会话更新（清除 cookie、新建会话），游客购物车无法读取旧会话购物车数据；数据库内旧`session_id`对应的`customer_id=0`记录会保留，产生孤儿数据
- 未登录用户点击结算，做权限拦截，正常跳转登录注册页面，不能直接进入下单流程
- 未登录添加商品，再执行登录操作，原会话下的购物车记录`customer_id`更新为登录用户 ID，购物车数据正常合并展示
- 已登录用户增删改购物车商品，数据正确保存至对应用户的购物车记录

### 关联数据库表

`oc_cart`

## 1. 数据总览首页（Dashboard 仪表盘）

### 业务描述

后台登录首页，为管理员提供商城整体运营数据可视化看板，汇总订单、销售额、客户、在线访客数据，展示订单状态占比与销售趋势图表。

### 核心功能

1. 核心指标卡片：总订单数、总销售额、客户总数、在线人数，支持跳转详情页面
2. 世界地图：展示访客访问地域来源
3. 销售分析图表：按时间维度展示订单、新增客户统计柱状图，支持时间筛选
4. 订单状态占比进度条：已完成订单、处理中订单、其他状态订单占比展示

### 测试关注点

- 新增订单 / 客户后，看板统计数值实时同步更新
- 修改订单状态，订单占比百分比同步变化
- 时间筛选器生效，图表数据跟随筛选条件变化
- 页面统计数据与 MySQL 底层数据表统计结果一致性校验

### 关联数据库表

`oc_order`、`oc_order_total`（销售额取 `code='total'`）、`oc_customer`、`oc_customer_online`、`oc_order_status`（订单状态占比）、`oc_product`（`viewed`）

## 2. 商品目录管理

### 业务描述

管理商城全部商品、文章资讯数据，维护商品分类、商品、分期、属性、规格、品牌、评价、文章资讯，控制前台商品与资讯内容展示。

### 核心功能

1. 商品分类：新增、编辑、删除商品分类，设置分类排序、启用 / 禁用状态
2. 商品管理：维护商品名称、价格、库存、图片、描述，商品上下架
3. 分期付款：配置商品分期付款方案，设置分期期数、每期金额
4. 分组筛选：商品筛选分组配置，前台实现筛选条件
5. 属性项和属性组：维护商品属性组、属性项，例如材质、产地
6. 规格：商品规格选项管理，颜色、尺寸等，支持规格联动改价
7. 品牌管理：商品品牌新增、编辑、删除维护
8. 下载商品：虚拟商品附件资源上传管理
9. 商品评价：查看、审核、删除买家商品评价
10. 信息文章：商城资讯文章管理，前台展示帮助、公告类文章

### 测试关注点

- 商品禁用后前台不可见，启用后正常展示
- 修改库存，下单扣减库存逻辑正确性
- 分期付款方案绑定商品，前台可正常选择分期
- 规格选项选择后价格联动变更
- 商品评价审核，未审核评价前台不展示
- 分类删除、排序、层级展示校验
- 文章发布 / 禁用，前台资讯页面展示控制

### 关联数据库表

`oc_product`、`oc_product_description`、`oc_category`、`oc_category_description`、`oc_product_option`、`oc_product_option_value`、`oc_review`、`oc_information`、`oc_information_description`、`oc_attribute*`、`oc_option*`、`oc_filter*`、`oc_product_filter`、`oc_download*`、`oc_recurring*`、`oc_product_recurring`

# 风险点记录

1. OCMOD 插件缓存不刷新，插件修改不生效
2. API 账号配置错误，接口调用鉴权失败
3. 统计报表可能存在统计逻辑 bug，需要页面与数据库双向核对
4. 优惠券、客户分组折扣逻辑容易出现边界问题
5. 分期、礼品券、退换货业务流程复杂，容易出现状态流转异常
